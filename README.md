# 南屯遙控車 (nantun-car-remote)

讓 micro:bit 收 iPad 控制台的訊號、驅動 MoonCar 差速馬達、回傳感測值的 MakeCode 擴充。積木全中文，形狀比照 micro:bit 原生輸入。

> 需 micro:bit **V2**；專案設定選 **No Pairing Required（免配對）**。本擴充會自動帶入藍牙，與無線電 radio 互斥。

## 加入方式

MakeCode →「擴充」→ 貼上本 repo 的 GitHub 網址 → 加入。

## 積木

**起手**
- `啟動遙控自走車`：開藍牙、開始收訊。放在「當啟動時」。
- `平板已連線?`（六角）

**收控制訊號**
- `當收到按鈕〔代號〕被按下` / `放開`（帽子）
- `按鈕〔代號〕被按下?`（六角）
- `方向盤數值`（圓角，−100~100）
- `搖桿 X` / `搖桿 Y`（圓角）

**車子動作**
- `設定左輪〔 〕右輪〔 〕`：左右不同就會轉彎（差速）。
- `停車`

**感測與回傳**
- `循跡值`（0~3）
- `回傳〔代號〕數值〔值〕給平板`

## 通訊協定

- iPad → 車：`FWD:1/0`、`LEFT:1/0`、`RIGHT:1/0`、`GO:1/0`、`A:1/0`、`B:1/0`、`STEER:-100~100`、`J:x,y`
- 車 → iPad：`代號:數值`（例如 `LINE:2`）

## 腳位（iCShop MoonCar）

馬達 P2/P8/P13/P14、循跡 P15/P16。
