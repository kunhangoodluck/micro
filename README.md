# 南屯遙控車 (nantun-car-remote)

驅動 MoonCar 差速馬達、解析 iPad 控制台訊號、讀循跡的 MakeCode 擴充。積木全中文。

> **藍牙不在擴充裡**：藍牙由「專案端」用官方「藍牙 Bluetooth」擴充處理，把收到的字串餵進 `處理收到訊號`。這樣擴充才不會有 native 建置衝突。

## 加入方式

1. MakeCode →「擴充」→ 貼本 repo 的 GitHub 網址 → 加入「南屯遙控車」。
2. 再加官方「藍牙 Bluetooth」擴充（會自動移除無線電）。
3. 專案設定選 **No Pairing Required**。需 micro:bit **V2**。

## 積木

- `準備自走車`：設腳位、顯示 ❌。放「當啟動時」。
- `處理收到訊號 [文字]`：把藍牙收到的字串餵進來解析。
- `按鈕 [代號] 被按下?`（六角）
- `方向盤數值`、`搖桿 X`、`搖桿 Y`（數值）
- `設定左輪 [ ] 右輪 [ ]`：差速。
- `停車`
- `循跡值`（0~3）
- `要回傳的訊息 代號 [ ] 數值 [ ]`：組回傳字串，再用藍牙送出。

## 專案端最少要接的藍牙水電

```
當啟動時 → 準備自走車 ＋ 藍牙 啟動 UART 服務
藍牙 當收到 UART 資料(換行) → 處理收到訊號( 藍牙 讀取UART字串直到(換行) )
藍牙 當連線 → 顯示 ✔ ；當斷線 → 停車 ＋ 顯示 ❌
```

## 腳位（iCShop MoonCar）

馬達 P2/P8/P13/P14、循跡 P15/P16。
